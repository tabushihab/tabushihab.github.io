# Taher Abushihab - Mechanical Engineering Portfolio

This folder is ready to publish as a GitHub Pages user site.

## Publish to GitHub Pages

1. Sign in to GitHub as `tabushihab`.
2. Create a new **public** repository named exactly `tabushihab.github.io`.
3. Upload the contents of this folder to the repository root. `index.html` must be at the top level of the repository.
4. Open the repository's **Settings** tab.
5. Select **Pages** under **Code and automation**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select the `main` branch and the `/ (root)` folder, then save.
8. Wait a few minutes, then open: `https://tabushihab.github.io`

## Before applying

- Open every page on desktop and mobile.
- Test the résumé and project-report download buttons.
- Confirm the email and LinkedIn links.
- Add the portfolio URL to your résumé and job application.

## Update later

- Replace images in `assets/images/` while keeping the same filenames, or update the paths in the HTML files.
- Add new project pages inside `projects/`.
- Update the project cards in `index.html`.
- The site uses plain HTML, CSS, and JavaScript; no build step is required.

## Important privacy note

This is intended for a public repository. Do not upload student ID numbers, confidential work materials, proprietary Apple repair images, customer data, or private class files you do not want publicly accessible.
